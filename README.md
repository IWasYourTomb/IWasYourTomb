## `$ projects --featured`

### 🗺️ RideMap

**A map for discovering spots.**

A side project focused on discovering and exploring spots on an interactive map, with web and native mobile clients.

- **Backend:** ASP.NET Core, .NET, SQL Server
- **Web:** Vue 3, TypeScript
- **iOS:** SwiftUI, Yandex Maps
- **Android:** Kotlin, Jetpack Compose, Retrofit, Hilt

[![GitHub](https://img.shields.io/badge/Explore_my_repositories-0D1117?style=for-the-badge&logo=github&logoColor=white)](https://github.com/IWasYourTomb?tab=repositories)

### ⚙️ Enterprise Microservices

**Distributed backend systems.**

Working with a microservice-based platform built with .NET, including service-to-service communication, event-driven messaging, authentication, authorization, audit logging and infrastructure.

- **Communication:** REST, gRPC
- **Messaging:** RabbitMQ
- **Caching:** Redis
- **Data:** SQL Server, Entity Framework Core
- **Infrastructure:** Docker Compose, Nginx, CI/CD

### 🧩 Fullstack Applications

**From API endpoints to the UI.**

Building applications with a .NET backend and a modern Vue frontend, with an emphasis on typed code, reusable components, validation, maintainability and clear separation of responsibilities.

- **Frontend:** Vue 3, TypeScript, Vuetify, Vite
- **Backend:** C#, ASP.NET Core
- **Data:** SQL Server, Redis
- **Tooling:** Git, GitLab CI/CD, GitHub Actions
